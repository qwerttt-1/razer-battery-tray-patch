# 雷蛇原托盘电量圆环补丁

让 Razer Synapse 原来的托盘图标显示鼠标电量：绿色圆环随电量变化，悬停显示设备名称和实际百分比，原来的点击和右键菜单继续保留。

适用于 Windows 64 位上的 Razer Synapse 4.X。安装器自动查找安装位置、读取实际版本，也可以手动选择程序或安装文件夹。

补丁按程序结构适配，不绑定某个 4.X 版本号。目前实机验证的是 4.0.896；其他 4.X 保留相同托盘和设备状态接口时可直接应用，接口发生变化时会提示停止。

[下载 Windows 单文件程序](https://github.com/qwerttt-1/razer-battery-tray-patch/releases/latest)

## 使用

1. 下载 Releases 中的 `RazerTrayPatchInstaller.exe`。
2. 双击运行，检查窗口中显示的安装位置和版本。检测到多个安装时，可在下拉框中选择。
3. 没有找到安装，或想指定其他位置时，点击“选择程序…”选择 `RazerAppEngine.exe`，也可以点击“选择文件夹…”选择它所在的安装目录。
4. 点击“应用补丁”，按 Windows 提示授权。程序备份原文件、正常退出所选 Synapse、应用补丁并重新启动。
5. 需要恢复时，选中同一安装位置，点击“恢复原版”。

已经安装同一版本时会提示无需重复应用。只需复制这个 EXE，不需要额外安装 Python、Node.js 或开发工具。操作完成后可以关闭程序，不增加启动项、服务或额外常驻进程。

## 图标与分档

内置 21 档、40 像素圆环设计、原始中心图案的 ICO。每档包含 16、20、24、32、40、48、64、72、96、128、256 像素图像，适配系统图标缩放。

| 实际电量 | 显示规则 | 示例 |
| --- | --- | --- |
| 低于 49% | 向下取 5% 档位 | 48% → 45% |
| 49%–51%，含两端 | 固定为 50% 档 | 49%、50%、51% → 50% |
| 高于 51% | 向上取 5% 档位 | 52% → 55%，79% → 80% |

悬停显示电量和充电状态。鼠标休眠时，圆环会继续显示本次 Synapse 运行中收到的最后一次电量，悬停标注 `Last reported`。如果唤醒后第一笔未充电读数突然变成 100%，圆环会暂留原档，等后续读数，最多等待 3 秒。多个电池设备同时存在时，圆环使用最低电量，悬停列出各设备。没有可显示的设备电量时恢复普通图标。

圆环所显示的设备正在充电时，图标从当前档位开始，每半秒升一档，到 100% 后跳回当前档位循环。悬停仍显示实际电量。停止充电后，圆环恢复显示当前档位。

## 实现与备份

补丁修改安装目录中的 `resources/app.asar`，在原托盘创建后加载更新模块，并修复菜单重建把悬停文字重置成“Razer”的问题。电量来自 Synapse 已有的内部设备状态事件。充电动画计时器只切换图标，不查询设备。

原版资源备份保存在安装目录的：

```text
resources/razer-battery-backup/original-app.asar
```

每个安装目录使用自己的备份和哈希记录。升级补丁时从该目录的原文件重新生成，恢复时核对备份与已安装补丁，避免混用不同版本的文件。已有 1.4 补丁可以直接升级。

工具内置文件及日志位于 `%LOCALAPPDATA%\RazerTrayBatteryPatch\installer-1.7.1`。工具正常运行不依赖 GitHub 或本仓库的在线文件。

Synapse 更新可能覆盖补丁。更新后重新运行安装器，确认新版本和安装位置后再应用；保留各版本自己的备份，不要把旧版 `app.asar` 复制到新版安装目录。

## 从源码构建

需要 Windows 64 位、Visual Studio / Build Tools 的 C++ 工作负载、Windows SDK 和 CMake。可使用 Visual Studio 自带的 CMake。

在项目根目录运行：

```bat
build.cmd
```

输出为 `build\RazerTrayPatchInstaller.exe`。程序使用静态 MSVC 运行库，内置脚本和图标，运行时只需 Windows 系统组件及受支持的 Synapse。

开发测试使用 Node.js 18 或更新版本，无第三方 npm 依赖：

```sh
npm test
```

测试覆盖电量分档、悬停文字、不同 4.X 版本号、内部变量重命名、旧补丁升级、重复应用、备份校验和恢复。跨版本测试使用构造的程序样本；实际兼容范围见上文。
